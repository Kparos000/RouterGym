# RouterGym Analysis Outputs

These files are generated from the local balanced 60k BM25-RAG inference dataset.
The raw JSONL input is intentionally excluded from git because it is large.
`balanced_60k_all_configs_flat.csv` is also a large local derived extract and is ignored.

## Metric Interpretation

- Classifier-derived category accuracy compares `predicted_category` /
  `classifier_predicted_category` with `gold_label`; it does not measure generated-answer
  correctness.
- Generated-category accuracy uses `generated_predicted_category` when available.
- Deterministic gold-resolution quality scores generated answers and resolution steps against the
  frozen gold-resolution set.
- Manual audit quality is produced only after reviewers fill the blinded manual audit CSV.
- Structural usability/reliability metrics include generation validity, parse errors, validation
  errors, raw response availability, and usable output rate.
